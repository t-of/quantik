# quantik — 4種の形で3目並べ、読み切りCPU

4×4の盤に4種の形を置き、縦・横・区画で4種を揃えたら勝ちの対戦パズル

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/quantik/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

4×4 の盤（2×2 の区画が 4 つ）に、●■▲✚ の 4 種の形を 2 個ずつ交互に置く。先手・後手は色で区別。

- 置いたマスと同じ行・列・区画に「相手の」同じ形がすでにあると置けない（自分の同じ形はよい）。
- 行・列・区画のどれかに 4 種の形がすべてそろえば（色は問わない）、置いた人の勝ち。
- 置ける手が 1 つもなければその手番の負け（引き分けはない）。

タップで形を選び、置けるマス（薄く光る）をタップして置く。「1手戻す」で直前の手に戻せる
（CPU 戦では CPU の手も合わせて戻る）。

CPU は最後まで読み切る（最強の 1 段階のみ）。初期局面は後手必勝なので、CPU が後手なら必ず勝つ。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

CPU（`ai.js`）のテスト:

```sh
node ai.test.mjs
```

開局ブック（`book.json`、駒 5 個までの全局面の勝ち負け）の作り直し（ai.js の読み切りを変えたら流す。20 秒ほど）:

```sh
node tools/solve.mjs
```
